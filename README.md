# ДФС — 16 состояний

Каталог картин, музыки и описаний для 16 состояний по методике дифференцированных функциональных состояний И. Н. Калинаускаса: 4 центра (1 Витальный, 2 Эмоциональный, 3 Ментальный, 4 Аккорд) × 4 ритма (A ∞ Бесконечность, B ~ Поток, C ▪ Дискретность, D ⚡ Распад).

Сайт: https://andeulin.github.io/dfs-16-states/

## Что где

```
docs/                        сайт (его отдаёт GitHub Pages)
  index.html                 вёрстка, стили и вся логика: фильтры, описания, плееры, просмотр картин
  data.js                    данные: 16 состояний — описание, картины, треки
  img/                       30 картин в jpg (1A-1.jpg, 1A-2.jpg, …)
  .nojekyll                  служебный файл для GitHub Pages
materials/
  pictures-original/         исходные картины (png): цифра в имени — центр, буква — ритм; «part2» — вторая картина
  reference-site-2026-08-17.pdf   распечатка прежнего сайта на Manus: эталон текстов описаний и списка музыки
```

В репозиторий намеренно не кладутся записи занятий и копия задач Manus: они личные и очень большие.

## Как это устроено

- Сборки нет: сайт открывается двойным кликом по `docs/index.html`.
- Описания состояний эталонные, как на прежнем сайте. Менять только по решению владельца.
- Карточки выровнены по высоте в ряду; у картин одинаковые плитки, картина показывается целиком.
- Фильтры по центру и ритму закреплены сверху. Ссылка на состояние: `…/#2C`, на центр: `…/#c2`, на ритм: `…/#rC`.
- Телефоны: проверено на ширине 320–412 px; просмотр картин листается свайпом.

## Как менять данные (`docs/data.js`)

Каждое состояние: `id`, `c` (центр), `r` (ритм), `desc` (описание), `imgs` (картины: `src`, `w`, `h`), `tracks`.
Трек: `{ "t": название, "a": исполнитель, "ym": "ТРЕК:АЛЬБОМ" }`, необязательное `note` — пояснение под плеером.

Как получить `ym`: открыть трек в Яндекс Музыке, адрес вида `music.yandex.ru/album/5434759/track/25156631` превращается в `"ym": "25156631:5434759"`. Если трека в Яндекс Музыке нет, поставить `"ym": null`: тогда вместо плеера будут ссылки на YouTube и VK.

Известные особенности музыки: «Try» Дженис Джоплин в Яндекс Музыке нет (ссылки на YouTube и VK); «Time» (Pink Floyd) и «I Will Always Love You» (Уитни Хьюстон) — только концертные записи, это подписано в плеере. Без входа в Яндекс Музыку плеер может проиграть только фрагмент.

## Публикация

GitHub Pages настроены на ветку `main`, папку `/docs`. Достаточно закоммитить и отправить изменения в `main`: сайт обновится через 1–2 минуты.
