# ДФС — 16 состояний

Каталог картин, музыки и описаний для каждого из 16 состояний по методике дифференцированных функциональных состояний И. Н. Калинаускаса.

Сайт: https://andeulin.github.io/dfs-16-states/

Статичная страница без сборки: `index.html` (вёрстка и логика), `data.js` (состояния, картины, треки), `img/` (картины).
